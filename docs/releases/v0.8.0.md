# Mac Status v0.8.0

상단바에 표시할 통계를 고르고, API 숫자에 계산식을 적용할 수 있습니다. 설정 창과 팝업의 클릭·포커스 처리, WakaTime 인증, 항목 편집 화면도 함께 개선했습니다. v0.7.6 이후 변경 사항을 모은 릴리스입니다.

## 상단바에 원하는 수치 표시

- CPU 외에도 메모리·저장공간, Codex·Claude의 5시간·주간 사용량, 제공되는 크레딧, WakaTime 기록 시간과 직접 추가한 통계를 선택할 수 있습니다.
- 비율을 제공하는 항목은 **값 그대로 / 사용률(%)** 중 표시 방식을 고를 수 있으며 선택은 다음 실행에도 유지됩니다.
- 드롭다운에 그룹 제목과 항목별 아이콘을 넣고, 선택한 항목은 민트색 체크와 굵은 글씨로 구분합니다.

## API 경로와 계산식

- **API 숫자 통계**에서 API 주소와 `A.B.C`, `data.0.value` 같은 JSON 경로를 지정합니다. 배열의 여러 숫자는 `data.*.value`와 **합계**로 읽을 수 있습니다.
- 값·한도 JSON 경로 아래에 독립 계산식을 추가했습니다. 각 경로에서 읽은 숫자를 `value`로 두고 `value * 2`, `(value + 5) / 2`처럼 사칙연산과 괄호를 사용합니다.
- 계산 순서는 **단일 숫자 또는 합계 → 계산식 → 값 배율**입니다. 계산식을 비우면 원래 숫자를 사용하며, 한도 계산식은 한도 JSON 경로가 있을 때 적용됩니다.
- 0으로 나누거나 계산 결과를 유한한 숫자로 표시할 수 없으면 카드·상세·상단바에 `null`을 표시합니다. 이전 정상 수치나 0으로 대체하지 않습니다.
- **JSON 값 그대로** 모드에서는 숫자·문자·참/거짓·객체·배열을 계산 없이 표시할 수 있습니다. 연결 실패나 경로 누락도 `null`로 구분합니다.

## 편집 화면과 클릭 안정성

- 빠지거나 잘못 입력한 항목은 팝업 알림 대신 입력칸의 빨간 `*`, 테두리와 짧은 안내로 표시합니다. 오류가 있는 탭으로 이동하며 값을 고치면 해당 표시가 사라집니다.
- 연결 테스트 결과를 편집창 아래에 표시하고, 입력 예시와 안내 문구를 정리했습니다.
- 버튼 여백 전체를 클릭할 수 있도록 보완하고, 창 활성화·시트·인증 창 사이에서 포커스를 잘못 가져오던 처리를 수정했습니다.
- 팝업이 열린 상태에서 설정 창을 누르면 팝업이 닫히면서 같은 클릭이 설정 탭에 전달됩니다. 상단바 아이콘은 팝업만 열며 뒤에 있는 설정 창을 함께 앞으로 가져오지 않습니다.
- 통계가 갱신되는 중에도 열린 드롭다운의 항목과 선택 동작을 유지합니다.

## WakaTime 개인 OAuth 토큰

통계 조회는 **`read_summaries` 권한의 개인 OAuth 토큰**을 사용하도록 전환했습니다. 기존 API 키를 사용한 통계 조회는 중단합니다.

API 키만 사용하던 경우 **설정 → 앱 설정 → WakaTime 연결 설정**에서 [개인 OAuth 토큰](https://wakatime.com/oauth)을 발급해 입력하고 **연결 테스트 → 저장**을 진행해 주세요. 토큰은 macOS 키체인에 저장합니다. 기존 WakaTime 설정 파일과 활동 추적용 API 키는 변경하지 않습니다.

## 로그인과 업데이트

- 로그인 과정의 별도 인증 창을 유지하고, 원래 연결 페이지가 인증 결과를 받도록 흐름을 보완했습니다. 인증 진행 중에는 사용량 확인이 끼어들지 않도록 처리합니다.
- Google 소셜 로그인·패스키는 서비스와 내장 웹뷰 정책에 따라 제한될 수 있습니다. 이번 변경이 모든 내장 로그인 제한을 해결하는 것은 아닙니다.
- 여러 업데이트가 있으면 설치된 빌드보다 새로운 최신 호환 버전을 선택하도록 업데이트 로직을 개선했습니다.

## 지원 환경

- Apple Silicon Mac, macOS 14 이상
- 배포용 Developer ID 서명·공증은 아직 제공하지 않습니다.

## 검증

- Swift 자동 테스트 250개, 배포 도구 테스트 5개 통과
- arm64 릴리스 빌드, 앱 서명과 ZIP·DMG 무결성 확인
- 업데이트 ZIP·피드의 EdDSA 서명과 SHA-256 체크섬 확인
- 사용자 확인: WakaTime 오늘·최근 7일 표시, 설정 창 클릭 시 팝업 닫기와 탭 선택, 상단바에서 설정 창을 올리지 않고 팝업만 표시
